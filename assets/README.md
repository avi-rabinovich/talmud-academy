# Source scan

`berachot-26a.jpg` is the Berachot 26a page image served at https://www.dafyomi.org/edafnew/Berachos/26a.jpg, downloaded for this local prototype on 2026-09-17. The source page https://www.dafyomi.org/index.php?daf=26a&masechta=brachos credits E-daf.com for its images. Attribution is displayed beside the image in the app. Redistribution rights for this specific scan have not been verified; review before public deployment.

The parsing exercises use manually mapped word boxes on the unmodified 1024 × 1549 image. The complete page is displayed. Quiz 1 maps the opening exchange; quiz 2 maps the next two exchanges, ending before מיתיבי. Both include five following words to allow an overly long selection. Quiz 3 continues from מיתיבי through ש״מ and includes the next-page catchword תנו as one overshoot word. The prose explanations are original teaching aids.
